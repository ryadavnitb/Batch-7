# AirFly Insights – Flight Data Visualization

## 📌 Project Overview
AirFly Insights is a data visualization project that analyzes flight delay patterns using real-world airline data.  
The project focuses on understanding delay causes, airline performance, and operational insights through visual analytics.

---

## 🎯 Objectives
- Analyze different types of flight delays
- Identify major delay causes
- Compare airline performance
- Visualize trends for better insights

---

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

---

## 📂 Files in This Repository
- `AirFlyInsightsDataVisualisation.ipynb` – Main analysis and visualization notebook
- `README.md` – Project documentation

---

## ▶️ How to Run
1. Open the notebook in **Google Colab** or **Jupyter Notebook**
2. Run all cells in order
3. Review generated graphs and insights

---

## 📊 Key Insights
- Weather and late aircraft are major delay contributors
- Delay patterns vary across airlines
- Visualization helps identify operational bottlenecks
