# Airline Flight Delay Analysis

**Infosys Data Science Internship Project**

## 📊 Overview
Analysis of 7M+ US flights (2015-2019) focusing on:
- Top routes & airport delays
- Cancellation patterns
- Seasonal trends

## 🛫 Key Findings
- **Atlanta**: 486K flights (world's busiest)
- **Carrier delays**: 62% of cancellations
- **Winter**: 2.3x higher cancellations
- **Best time**: Early morning flights

## 📈 Visualizations
- Top 10 routes bar chart
- Airport delay heatmap (10x10)
- Airport bubble map (size=traffic)
- Cancellation reasons pie chart
- Monthly trends

## 🛠️ Tech Stack
Python | Pandas | Matplotlib | Seaborn
