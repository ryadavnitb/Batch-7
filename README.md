# AirFly Insights: Airline Delay and Cancellation Analysis

## Project Overview
This project analyzes airline flight operations data from August 2019 to August 2023 to uncover patterns in delays, cancellations, routes, and seasonal behavior using data visualization techniques.

The goal is to understand how large-scale airline systems manage operational stress and maintain stability.

---

## Dataset
Source:  
US Department of Transportation, Bureau of Transportation Statistics  
(Kaggle Airline Flight Dataset)

Coverage:
- Millions of flight records
- Delay types, cancellations, routes, airports
- Multi-year operational data

---

## Tech Stack
- Data Processing: pandas, numpy
- Visualization: matplotlib, seaborn
- Optional Tools: Streamlit, Power BI
- Documentation: Jupyter Notebook, GitHub

---

## Project Structure
- Data Cleaning and Feature Engineering
- Exploratory Data Analysis
- Delay Cause Analysis
- Airport and Route-Level Analysis
- Seasonal and Cancellation Analysis
- Final Visualization and Reporting

---

## Key Insights
- Delays are the primary operational response to congestion
- Cancellation rates remain stable across seasons
- High-traffic airports manage congestion efficiently
- Route frequency impacts reliability more than delay averages
- No single factor dominates cancellations

---

## Deliverables
- Cleaned and engineered dataset
- Visual analysis notebooks
- Final presentation slides
- GitHub repository with code and visuals

---

## Conclusion
The findings highlight operational resilience in airline systems, where delays absorb disruptions and cancellations are minimized even under seasonal and congestion pressures.
